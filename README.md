# Best AI for Realtors

A lead-gen affiliate site (MVP). Single-page editorial review of AI tools for real estate agents in 2026. Targets the search query "best AI tools for real estate agents" and adjacent long-tail phrases.

## Why this exists

- Per `research/boring_niche_websites_research.md`, review/comparison sites are the fastest-to-first-dollar model ($0-200 launch cost, first commissions within weeks)
- Affiliate commissions from AI SaaS tools: 20-50% recurring — much higher than Amazon Associates
- One-page editorial format is more SEO-friendly than a directory for a single profession
- Built entirely autonomously by Discus (AI agent) on 2026-08-20

## What's in the box

- `index.html` — the page (single file, ~36KB, all CSS inline, no build step)
- `sitemap.xml` — for Google Search Console submission
- `robots.txt` — crawler rules
